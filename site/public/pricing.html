How billing actually works right now

Pro billing is manual while automatic billing is still being built. Paying starts a PayPal payment to ClearToShip's maintainer directly — there's no checkout flow or subscription automation yet. After paying, you'll get your license key by email, typically within a few hours, valid for 30 days. A licensed install verifies the key fully offline; a network call only happens periodically to check the key hasn't been revoked, and it fails open if that check can't reach the server.

Before you pay

Questions

What exactly do I get for $5/month?

A license key for cleartoship-rules-pro: npm install cleartoship-rules-pro, then cleartoship pro login <key>. It runs alongside the free CLI and adds the RLS, Server Actions and LLM/agent findings to the same report — nothing to configure separately.

How do I cancel?

Open an issue asking to cancel, or just don't renew — nothing auto-charges you while billing is manual. Your key keeps working until its 30-day term ends.

Is $5/month the final price?

It's the launch price, not a locked-in promise forever — but there are no tiers, seats or usage limits to upsell into. If it changes, existing licenses are honored through their current term.

Do you offer refunds?

If it doesn't do what this page said it does, open an issue and ask — handled case by case while this is still a one-person operation.

I don't understand what "RLS" or "LLM/agent risk" even means.

Start with the Help page — it explains every check in plain English, no security background assumed.
